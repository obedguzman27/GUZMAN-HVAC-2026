Versión

Esta sección solo la ve el admin — configuración sensible del negocio, no del día a día.

Socios (reparto)

Cada semana se reparte en partes iguales entre los socios de la lista — con uno solo, se lleva todo. Para cada uno, define si recibe tax y qué porcentaje. El primer socio de la lista es quien recibe los ajustes manuales (Movimientos → Ajuste).

Reportes y exportación

A diferencia del respaldo (que es un archivo técnico para restaurar), esto genera reportes para leer, imprimir o abrir en Excel.

El Excel trae una hoja por cada área (Movimientos, Invoices, Nómina, Empleados). El PDF es un resumen para imprimir o guardar.

Bases de datos

Crea las bases de datos con el nombre que quieras (ej. Guzman HVAC Airton, Guzman HVAC Estrada). Luego, abajo, asignas cada usuario a una de ellas.

Usuarios y a qué base de datos entran

Elige a qué base de datos entra cada usuario, apruébalos y define su rol. Los usuarios en la misma base de datos ven la misma información.
